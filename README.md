# Z01coder.github.io

Сайт-портфолио Алексея Золотухина (Z01coder): вайб-кодинг и AI-ассистированная разработка для малого бизнеса.

**Публичная ссылка:** https://z01coder.github.io/

## Что на сайте

- Hero с оффером для малого бизнеса и живым терминалом «сборки проекта»;
- Кейсы: лендинг «СтальВектор», трекер «Такт», калькулятор стоимости шкафа-купе + сетка «ещё проекты»;
- Услуги и открытый прайс: лендинги от 13 500 ₽, боты, калькуляторы, трекеры; пакеты «База» и «База+»;
- Процесс работы в 5 шагов (бриф → ТЗ → оценка → спринты с демо → правки и передача);
- Обо мне: фото, IQ-блок, таймлайн опыта, стек технологий, кнопка «Скачать резюме (PDF)»;
- Микроблог о разнице вайб-кодинга и AI-Driven разработки (с G-Man);
- FAQ и контакты (VK-сообщения).

## Технологии

- Один файл `index.html`: чистые HTML + CSS + vanilla JS, без фреймворков и сборщиков;
- Шрифты: Space Grotesk (латиница/цифры) + Manrope (кириллица) + JetBrains Mono (терминал);
- Анимации: печатающийся терминал, scroll-reveal (IntersectionObserver), счётчики цифр, ховер-эффекты карточек;
- Matrix-фон на canvas + пасхалка `matrix_rain.html`;
- Уважение к `prefers-reduced-motion`.

Собран с помощью AI-ассистированной разработки (OpenCode, ZCode).

## Как запустить локально

Статический сайт — сборка не нужна:

```bash
git clone https://github.com/Z01coder/Z01coder.github.io.git
cd Z01coder.github.io
python -m http.server 8137
# открыть http://127.0.0.1:8137/
```

## Деплой

GitHub Pages из ветки `main` — обновляется автоматически после каждого пуша.
